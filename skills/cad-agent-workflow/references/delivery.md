# 来图制图交付

按题面或客户确认记录单位、零件用途、关键尺寸、基准、材料公差要求、版式和文件格式。客户指定 CAD 版本和特征树时，记录软件与原生交付后缀。用户只要求学习或复刻时，可先交成品和关键步骤。

按原件复杂度、绘制、复核及约定改稿估算工作量。扫描图先检查尺寸是否足以重画。复核客户给出的一个已知尺寸后，再约定是否能交带尺寸的工程图。对付费单确认所用 CAD 许可覆盖该用途。

对于有改版的任务，保留已确认的基准和原始批注，汇总修改点。提交同版的源图、PDF 和模型。客户新增规格或零件时，重算相应工作量。可用下面的文字向客户收集资料。

> 请发原图、带尺寸的草图或已有 CAD 文件，并说明单位、用途、重点尺寸和交付格式。如果有指定 CAD 版本、图层、图框或三维特征要求，请一并发我。我看原件确认工作量，先发 PDF 或模型预览核对，再交约定的源文件。
