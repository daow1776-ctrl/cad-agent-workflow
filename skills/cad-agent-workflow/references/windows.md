# Windows 运行环境

## 路径由任务提供

读取当前任务、项目配置或用户另行提供的设置，确定输入、工作根目录、交付目录及可执行文件。可用当前进程的 `CAD_AGENT_ROOT` 表示选定的工作根目录；本技能不设置固定盘符、用户名、桌面路径或作者。

多任务可在工作根目录下分设 `tools`（运行工具）、`cache/jobs/<任务名>`（可再生成中间文件）、`exchange/<任务名>`（MCP 文件交换）、`deliverables/<任务名>`（最终文件）。这些是可选目录约定，不会自动创建或覆盖用户的布局。保持系统 TEMP 和应用配置正常；缓存清理避开运行中的任务、工具和交付件。

使用可执行文件完整路径，通常无须修改全局 PATH。先确认文件存在、版本和运行权限。需要桌面副本时以用户确认的实际桌面为准，沙箱会话返回的路径可能不同于登录用户会话。

## 工具与兼容性

| 工具 | 准备与边界 |
| --- | --- |
| AutoCAD / Core Console | 从实际安装目录、PATH 或 Autodesk 注册信息查找 `accoreconsole.exe`。随附转换脚本曾以简体中文 AutoCAD 2024 测试，其他版本和打印配置需验证。使用独立配置目录；命令提示及纸张名可能随语言变化。 |
| CAD Operations | 原参考版 `e6b1a5f` 的机械修订运行时要求 Python 3.12。保留完整运行时、知识库、模板及依赖。其内置原生执行器针对 AutoCAD 2023/R24.2；AutoCAD 2024 可走独立 Core Console 路线，不能据此宣称原执行器兼容。 |
| SolidCraft | 独立参数化 CAD。优先使用已注册 MCP；没有时可以用官方 CLI 启动任务级 MCP。随附辅助脚本参考版本为 0.30.1。文件许可范围必须覆盖当前任务所需路径。 |
| SOLIDWORKS | 要求实际安装且可用的授权会话。2025 曾验证草图、拉伸、驱动尺寸修改及 SLDPRT 保存重开；装配、工程图和复杂特征依任务另验。 |

升级软件或换电脑后，验证本次任务依赖的操作。已有失败原因且环境未改变时，不反复重试相同方法。原生程序崩溃或卡死后保留日志和最后一次验证通过的文件，再选择其他可用路径。

## 命令行运行

- AutoCAD 转换脚本显式接收 `--exe` 和 `--profile`，分别是实际 Core Console 文件和已建立的独立配置目录。见 [二维制图](drafting.md)。
- CAD Operations 使用独立的 Python 3.12 环境；若用 `PYTHONPATH`，只给当前进程配置依赖目录及 `runtime/cad-2d-skill/src`。
- SolidCraft MCP 的 `--allow-path` 使用任务所需目录，不因导出失败扩大到整个磁盘。见 [三维建模](modeling.md)。
