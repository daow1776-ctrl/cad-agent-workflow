# CAD Agent Workflow

通用 Windows CAD 技能，整合 CAD Operations 的二维修订与复核、SolidCraft MCP 的三维建模，以及 AutoCAD / SOLIDWORKS 的原生交付路径。

入口为 [SKILL.md](SKILL.md)，安装与依赖见 [setup.md](references/setup.md)。把本文件夹整体安装到宿主可发现的技能目录，然后调用：

> 使用 $cad-agent-workflow 按给定尺寸制作这张机械图，交 DWG、PDF 和关键尺寸核对结果。

个人路径、署名、语言和交付偏好另存为本地配置，在需要时与任务一起提供。技能不附带 CAD 软件、个人作业或个人配置。
